# 🎂 Asmit Birthday Website

A simple 3-page birthday surprise website for Asmit.

## Files
- `index.html` — Welcome / surprise page
- `page2.html` — Birthday page
- `page3.html` — Final message

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload all files to a GitHub repository and enable **GitHub Pages** from Settings → Pages.
